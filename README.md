# DeepSeek 对话导出工具

一键将 DeepSeek 网页端的 AI 对话导出为 Markdown 文件。

## 安装

1. 安装脚本管理器：[Tampermonkey](https://www.tampermonkey.net/) 或 [ScriptCat](https://docs.scriptcat.org/)
2. [点击安装脚本](链接待替换) 或手动复制 `script.js` 内容到脚本管理器

## 使用

1. 打开 [DeepSeek Chat](https://chat.deepseek.com/)
2. 进行对话后，点击右下角 **导出Markdown** 按钮
3. 文件自动下载，文件名格式：`对话标题-日期时间.md`
